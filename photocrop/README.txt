PhotoCrop - cut applicant photos out of scanned forms

HOW TO START
 Double-click PhotoCrop.exe. Nothing to install.
 If Windows says "Windows protected your PC": click "More info", then "Run anyway".

THE 5 STEPS
 1. Source folder      - the folder with the scanned forms.
 2. Destination folder - where the cropped photos go (you are asked when you export, if not set).
 3. Find the photos - choose one:
      Auto-select all  - finds the photo on every form, then WAITS for your review.
      Auto-crop all    - finds the photo on every form and exports straight away, no review.
      Copy box to unchecked - uses the box on this image for every image that has none yet.
 4. Review - go through the images that need a look (about 1.5 minutes of detection for 600 forms):
      drag the box edges/corners to fit the photo, then press Enter (or click Confirm).
      "Next to check" jumps to the next image that needs a look.
      FREE SHAPE (like a document scanner): if the photo sits crooked on the scan, click "Free shape" (or press Q).
      The box gets four round corners. Drag each corner onto a corner of the photo. The preview on the right shows the
      photo straightened, and that straightened, upright photo is what gets exported. Click "Free shape" again (or Q)
      to go back to a plain rectangle. Drag inside the shape to move all four corners together.
 5. Export:
      Done & Export    - exports ONLY images that are new or changed since the last export.
      Update this one  - exports just the image you are looking at.

WHAT EACH FILE SHOWS (icon and note next to every file)
   green check   done: exported with a confident box, or a box you confirmed
   amber triangle  "better crop?" / "check": only a guess, it may need a better crop
   red cross     "not done": no photo found, or the export failed
   blue dot / purple diamond  "waiting": has a box but is not exported yet (or you changed it)

THE TABS ABOVE THE LIST  (All / check / triangle / cross, with counts)
 Click a tab to show only those files, e.g. the cross tab lists every file that is not completed.
 After "Auto-crop all" the app opens on the tab that needs you first, and tells you the numbers.

UPDATING FILES AFTERWARDS (one or many)
 - One file: click it, fix the box, press Enter, then "Update this one" (or Done & Export).
 - Many files: Ctrl+click or Shift+click to select several (Ctrl+A selects all shown in the tab).
     "Copy box to N selected" puts the current box on all of them (they then show as waiting).
     "Update N selected" re-exports just those into the destination folder.
 - "Done & Export" always writes only what is new or changed, so nothing else is touched.
 Your boxes and the exported marks are remembered per source folder, so you can close the app and come back.
 If you change the destination folder, everything counts as not yet exported there.

KEYS: Left/Right (or Up/Down) = previous/next image in the list, Enter = confirm box, Esc = undo edits on this image,
      Q = switch between a plain rectangle and a free shape (four corners).
      Tab / Shift+Tab = move between the buttons and the file list (a ring shows where you are), Enter or Space = press the button.
Exporting overwrites a file with the same name in the destination folder.
